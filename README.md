# project-vehicles-sprint7
Como crear una app usando streamlit y rendel.  
Crear un entorno virtual de python y clonar un repositorio
Esta es una app web que analliza los datos de los vehiculos usados
La cual muestra una tabla de datos y permite generar gráficos interactivos, como el histograma de odometer y el grafico de dispersión.
Para usarla, solo da clic en los botobes que aparecen debajo de los datos en la aplicación de Render ( https://project-vehicles-sprint7.onrender.com/ )
